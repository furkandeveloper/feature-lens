# Getting help

FeatureLens uses GitHub Issues for support.

- **Questions and problems using FeatureLens:** first check the
  [README](README.md), especially
  [Recovering from a refusal](README.md#recovering-from-a-refusal), and
  the [manifest reference](docs/MANIFEST.md) for validation codes and exit
  codes. If that doesn't answer it, open an issue.
- **Bugs:** open an issue with the bug report template and a minimal
  reproduction.
- **Feature ideas:** open an issue with the feature request template.
- **Security vulnerabilities:** do not open a public issue; follow
  [SECURITY.md](SECURITY.md).

Please don't include private source code or credentials in issues. Most
problems can be shown with the bundled `examples/sample-shop` project or a
few lines of code.
